Read in this order.

1. [ARCHITECTURE.md](ARCHITECTURE.md): what Sonix is, what exists today, what is planned.
2. [DECISIONS.md](DECISIONS.md): decision records. Check whether one is accepted or only proposed.
3. [PORT-MAP.md](PORT-MAP.md): the port from SourbyCraft: units, order and state. Claim here before porting.
4. [GLOSSARY.md](GLOSSARY.md): domain terms and their Rust names.
5. [UPSTREAM.md](UPSTREAM.md): following Pumpkin, and every Pumpkin file Wheeped has changed.
6. [TRYING-A-BUILD.md](TRYING-A-BUILD.md): getting a Linux binary of a branch and starting it behind a proxy.
